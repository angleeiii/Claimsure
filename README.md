\# Claimsure



\"Lost Item Reporting, Matching, and Verification System for an Amusement Park\"



\- Project Overview



Claimsure is a desktop application project designed to help users report lost and found items, support matching between reported items, and assist administrators with item verification.



\- Planned Technologies



\- Python

\- CustomTkinter

\- MySQL

\- XAMPP



\## Planned Modules



\- User registration and login

\- User dashboard

\- Administrator dashboard

\- Lost and found item reporting

\- Item matching

\- Item verification
